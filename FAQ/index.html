What is Oversight monitoring?

Oversight is monitoring the physical process assets (like pumps and valves) as well as the underlying control infrastructure (including PLCs and VFDs).

Process Assets

The system tracks physical process telemetry – such as temperature, vibration, pressure, etc., so it can visually verify if the mechanical equipment is healthy or experiencing issues.

Control Assets

The system continuously supervises the connected control infrastructure (PLCs) that physically manage the process assets. The system tracks infrastructure health parameters, such as CPU load, memory usage, and communication latency.
